Team 4 — Student Budget Tracker
A simple web application that helps university students manage their money, track income and expenses, and set a monthly budget.

📌 Project Overview
The Student Budget Tracker is designed to help students understand their spending habits and manage their finances more easily. Users can record transactions, view their total balance, organize expenses by category, and monitor their monthly budget.

✨ Features
Dashboard: View total balance, income, and expenses.

Add Transactions: Record income and expenses with descriptions and amounts.

Categories: Organize transactions into Food, Transport, Housing, Education, and Other.

Monthly Budget: Set a budget and monitor spending progress.

Transaction History: View saved transactions and delete unwanted records.

Local Storage: Save transaction and budget data in the browser.

Responsive Design: Use the application on desktop and mobile screens.

🛠️ Technologies Used
HTML5 — Page structure

CSS3 — Styling and responsive design

JavaScript — Application logic and calculations

Browser Local Storage — Saving user data

GitHub — Version control and collaboration

GitHub Pages — Website hosting

🚀 How to Run the Project
Open the project repository on GitHub.

Download the project files or clone the repository.

Keep index.html, style.css, and app.js in the same folder.

Open index.html in a web browser.

Add transactions and set a monthly budget to start tracking your finances.

No additional software installation is required to run the basic application.
